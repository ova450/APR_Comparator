# Решения по первому этапу (структура + Domain Model)

Зафиксированные решения:

1. **Целевой фреймворк**: .NET 9.
2. **Первичные ключи**: везде `int Id` (BaseEntity).
3. **Имена свойств** (`AmountFinanced`, `LoanCashback` и т.п.) — окончательные. БД создаётся
   с нуля при первом запуске (миграциями EF Core), поэтому исправленные имена и станут
   настоящими именами столбцов — маппинг через Fluent API на "старые" имена не нужен.
4. **`CbrLimit.LargeSumMinimum`** — окончательное имя (было обрезано на ER-диаграмме как
   "LargeSumLi...").
5. **`Offer.Mode` / `Offer.Status` / `CbrValidation.Status`** — остаются `string`, набор
   значений пока не определён. Вернёмся к вопросу enum, когда значения будут известны.
